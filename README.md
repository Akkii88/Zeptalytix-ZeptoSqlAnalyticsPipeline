# Zeptalytix — Zepto SQL Analytics Pipeline

End-to-end Zepto e-commerce data analysis project using SQL, Python EDA, Dockerized Postgres ETL, and reproducible analytics artifacts.

This repository contains a compact, hands-on SQL data analysis project built around an e-commerce inventory dataset (zettos/Zepto-style). The goal is to demonstrate common data-analyst workflows: ingestion, cleaning, exploration, and deriving business insights with SQL.

Contents
- `Zepto_SQL_data_analysis.sql` — core SQL script with table DDL, import examples, EDA and analysis queries.
- `zepto_v2.csv` — raw dataset (CSV).
- `notebooks/EDA.ipynb` and `notebooks/EDA.py` — compact EDA examples (pandas + plots).
- `plots/` — example output plots (generated by the EDA script).
- `tests/data_quality.py` — small data-quality checks script.
- `LICENSE` — project license (MIT).

Quick overview
- Create a SQL table for the inventory dataset
- Import the CSV into a SQL client (Postgres recommended)
- Run clean-up steps (remove invalid rows, convert units)
- Execute business-driven analysis queries (revenue, stock, discounts, price-per-gram)

Getting started
1. Clone or download this repository and open the folder locally.

2. Load data into PostgreSQL (example using `psql`):

```bash
createdb zepto_analysis
psql -d zepto_analysis -f Zepto_SQL_data_analysis.sql
\copy zepto(category,name,mrp,discountPercent,availableQuantity,discountedSellingPrice,weightInGms,outOfStock,quantity) FROM 'zepto_v2.csv' CSV HEADER
```

Notes: if you prefer to explore the dataset without Postgres, you can load `zepto_v2.csv` with Python/pandas:

```python
import pandas as pd
df = pd.read_csv('zepto_v2.csv', encoding='utf-8')
df.head()
```

Examples & quick EDA (runs locally)

1) Create and activate a Python virtual environment, then install dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2) Run the compact EDA script to generate example plots in `plots/`:

```bash
.venv/bin/python notebooks/EDA.py
```

3) Run simple data-quality checks:

```bash
.venv/bin/python tests/data_quality.py
```
